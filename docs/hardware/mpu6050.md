# MPU6050 Sensor

## Purpose and interface

The MPU6050 supplies three-axis acceleration measurements to the ESP32 for local motion and impact classification. It uses I2C on SDA GPIO21 and SCL GPIO22. Its default I2C address is `0x68` (address selection can be changed with AD0).

## Acceleration data

Firmware reads Ax, Ay, and Az in units of g. The readings include gravity, so a stationary sensor has a vector magnitude near 1g. Firmware calculates the vector magnitude from all three axes rather than classifying from one axis alone, then compares it with 1g.

## Range

The current `MPU6050_light` library setup calls `mpu.begin()` without an accelerometer-range argument. Its default is accelerometer configuration 0, **±2g per axis**. Keep this range for the current demo thresholds. Consider ±4g later only if measured impacts saturate the current per-axis range; wider range reduces measurement resolution.

## Simulation limitations

Wokwi exposes acceleration-axis controls in g, which are useful for deterministic SAFE/WARNING/DANGER checks. These controlled values do not establish real impact response, sensor calibration, mounting effects, or physical cargo-damage limits. A Wokwi test is not a substitute for calibrating real hardware.
